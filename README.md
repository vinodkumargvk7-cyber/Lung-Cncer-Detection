🫁 Lung Disease Detection using Deep Learning
📌 Project Overview
This project focuses on detecting lung diseases using deep learning techniques applied to medical imaging data. The goal is to assist in early diagnosis by building an accurate and efficient AI model.
The system uses convolutional neural networks (CNNs) to analyse lung images (such as X-rays or CT scans) and classify them into disease categories.
🎯 Objectives
Build a deep learning model for lung disease classification
Improve diagnostic accuracy using AI
Automate feature extraction from medical images
Evaluate model performance using standard metrics
🧠 Methodology
Data preprocessing and image normalisation
Splitting dataset into training, validation, and testing
Model development using CNN architecture
Training using labelled lung image datasets
Evaluation using performance metrics
